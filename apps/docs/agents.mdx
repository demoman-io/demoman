## Claude Code, Codex, Cursor and OpenCode

```bash
npx demoman setup
```

Setup connects every one of these it finds on your Mac:

| Agent | Setup adds |
| --- | --- |
| Claude Code | the Demoman plugin |
| Codex | the Demoman plugin |
| Cursor | an entry in `~/.cursor/mcp.json`, and the `record-demo` skill |
| OpenCode | an entry in `~/.config/opencode/opencode.json`, and the `record-demo` skill |

Demoman's tools then run without asking. Setup pre-approves them in Claude
Code, Codex and Cursor and says so; OpenCode needs no approval unless its own
settings ask for one.
Restart the agent before your first demo.

Demoman then updates itself in each agent. For Cursor and OpenCode, run setup
again after removing the Node that ran it: their entries name that Node's
`npx`.

## Any other agent

<Steps>
  <Step title="Add the MCP server">
    Add Demoman to the agent's MCP servers, in the form its tab below shows.
  </Step>
  <Step title="Add the record-demo skill">
    The skill tells the agent to read Demoman's recipe first. Fetch it into
    the agent's skills folder, named in its tab:

    ```bash
    curl -fsSL --create-dirs -o <skills folder>/record-demo/SKILL.md \
      https://raw.githubusercontent.com/demoman-io/plugins/main/skills/record-demo/SKILL.md
    ```
  </Step>
</Steps>

Then restart the agent. These are expected to work, not yet run.

<Tabs>
  <Tab title="Pi">
    ```bash
    pi mcp add demoman -- npx --prefix ~/ -y demoman@latest mcp
    ```

    Skills folder: `~/.pi/agent/skills`
  </Tab>
  <Tab title="Kimi Code">
    In `~/.kimi-code/mcp.json`:

    ```json
    {
      "mcpServers": {
        "demoman": {
          "command": "npx",
          "args": ["--prefix", "~/", "-y", "demoman@latest", "mcp"]
        }
      }
    }
    ```

    Kimi Code asks before each call unless `~/.kimi-code/config.toml` allows
    them:

    ```toml
    [[permission.rules]]
    decision = "allow"
    pattern = "mcp__demoman__*"
    ```

    Skills folder: `~/.kimi-code/skills`
  </Tab>
  <Tab title="Hermes">
    With Hermes running on this Mac:

    ```bash
    hermes mcp add demoman --command npx --args --prefix ~/ -y demoman@latest mcp
    ```

    Skills folder: `~/.hermes/skills`
  </Tab>
  <Tab title="DeepSeek dsh">
    In `~/.dsh/profiles/web/cordis.patch.yml`, a `@deepseek-ai/dsh-mcp-client`
    row with `transport: stdio`, `command: npx`,
    `args: ['--prefix', '~/', '-y', 'demoman@latest', 'mcp']`, and `cwd` set to your
    project.

    Skills folder: `~/.dsh/skills`
  </Tab>
  <Tab title="Other">
    Give the agent this stdio server:

    ```json
    {
      "command": "npx",
      "args": ["--prefix", "~/", "-y", "demoman@latest", "mcp"]
    }
    ```

    Then fetch the skill into wherever the agent reads skills from.
  </Tab>
</Tabs>
