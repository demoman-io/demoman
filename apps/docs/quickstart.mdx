## Requirements

macOS, Node 20 or later, and Claude Code, Codex or Cursor. Another agent
takes two more steps: see [Agents](/agents).

<Steps>
  <Step title="Set up">
    ```bash
    npx demoman setup
    ```

    Setup downloads Chromium (about 190 MB) and connects Demoman to each
    coding agent it finds, pre-approving its tools so they run without asking.
  </Step>
  <Step title="Restart your agent">
    Quit and reopen it, so it loads Demoman's tools.
  </Step>
  <Step title="Ask for a demo">
    ```text
    make a demo of demoman.io/sample
    ```

    Your agent drives Demoman's browser out of sight, and the video lands in
    `~/Downloads`.
  </Step>
  <Step title="Now try your own app">
    ```text
    make a demo of the new checkout flow
    ```
  </Step>
</Steps>
