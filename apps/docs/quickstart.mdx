## Requirements

macOS or x86_64 Linux, Node 20 or later, and Claude Code, Codex, Cursor or
OpenCode. Another agent takes two more steps: see [Agents](/agents). On Linux,
Chromium also needs system libraries: setup names the one `sudo` command that
installs them; run it, then setup again.

<Steps>
  <Step title="Set up">
    ```bash
    npx demoman setup
    ```

    Setup asks which agents to connect, the export quality and whether pull
    requests get a demo, then downloads Chromium (about 190 MB) and connects
    Demoman, pre-approving its tools so they run without asking.
  </Step>
  <Step title="Restart your agent">
    Quit and reopen it, so it loads Demoman's tools.
  </Step>
  <Step title="Ask for a demo">
    In your app's repo:

    ```text
    make a demo of the feature we just built
    ```

    Your agent drives Demoman's browser out of sight, and the video lands in
    `~/Downloads`.
  </Step>
</Steps>
