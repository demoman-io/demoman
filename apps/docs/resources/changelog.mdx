<Update label="Unreleased" description="Refresh compares the settled page">
  - A refresh compares each step's page once it settles: a spinner, caret or slow answer no longer reads as changed. Unsettled pages are named.
  - The first refresh after updating records each flow again and replaces its files once, even if the app did not change.
  - A video recorded before this release can't be added until it is recorded again.
  - A refresh is about a second longer per video.
</Update>

<Update label="0.9.4" description="CI setup that asks first">
  - Your agent's `ci` tool no longer starts your app's commands; `npx demoman setup --ci` shows them and asks first.
  - A deployment or release refresh skips commits not on the default branch.
  - Tokens in a page's address are kept out of saved files.
  - Demoman needs Node 20.12 or later, and says so.
  - Fixes: phone recordings at scale 1 keep their motion, exports render their queued edit, and a failed `signin` keeps the working session.
</Update>

<Update label="0.9.3" description="Pinned dates, and a steadier Studio">
  - `.demoman/app.json` may pin `now`, so a refresh records the app at the same instant every time and moved dates never count as a change. The app reads it from `DEMOMAN_NOW`.
  - The camera holds a drag's frame after the drop until the pointer moves on.
  - The Studio's lanes are brighter and taller, and its Export panel is calmer.
  - Previews and Reveal work on Linux, and `status` says the browser is not installed when Chromium's Linux libraries are missing.
  - Add finds a flow's checkout past a newer recording in another repo, and a sign-in on another localhost port no longer blocks it.
</Update>

<Update label="0.9.2" description="An easier Add to repo, and runs that follow a single-page app">
  - Add to repo opens its sheet at once, with Folder and File name fields, and lists each file it wrote.
  - Set up CI sits beside a project's heading in the Studio, so CI can be set up without adding a flow.
  - A run carries on when a single-page app changes its own address, such as a search that writes `?q=`.
  - A stopped run says "Stopped at script step N of M", counting steps the way the script does.
</Update>

<Update label="0.9.1" description="CI setup that works the first time, and refreshes you can trust">
  - An optional `reset` in `.demoman/app.json` runs before each flow, so one flow's changes never show in the next.
  - `.demoman/app.json` may leave out `env`, `secrets` and `services`; a refused file names the field.
  - A refresh records a rough video once more before delivering it with a note.
  - The refresh workflow can be run by hand from the Actions tab. A workflow set up earlier gets this when you add `workflow_dispatch:` under its `on:`.
  - Setup turns on the Actions setting before it sets any secret, and says who can change it when an organisation refuses.
</Update>

<Update label="0.9.0" description="Set up CI from one plan, or from the Studio">
  - `npx demoman setup --ci` checks the refresh from a clean checkout, shows one plan, and on one confirmation sets the secrets, opens a "Set up Demoman" pull request and watches its first run.
  - `.demoman/app.json` records how the app starts; `refresh` starts the app from it. If your own workflow started the app before `demoman refresh`, delete that step.
  - The refresh runs after a deployment, when a release is published, or once a day; each merge is offered, never the default.
  - The Studio's Add to repo and Remove from repo add and remove flows from a card, row or Export panel.
  - An unchanged refresh on a GitHub runner takes about 11 seconds, down from about 90.
</Update>

<Update label="0.8.2" description="Video as code, flows in the repo, and a library you can search">
  - A script can set where the video starts and ends with `trim`, and each click's zoom with `zoom`.
  - `demoman keep` is now `demoman add`, and repo flows live in `.demoman/flows/` with a receipt in `.demoman/receipts/`. `demoman remove` and `demoman join-flow` are new.
  - `refresh` prints `changed`, `added`, `uncompared`, `unchanged` or `failed` per flow. `add --deliver files` keeps videos out of git.
  - The Studio's library is grouped by project, searchable with `/`, and has a sortable List view with bulk delete.
  - The Export panel makes an MP4, GIF and stills in one go.
</Update>

<Update label="0.8.1" description="Wallpapers, and videos that stay current">
  - Fourteen built-in wallpapers for the background, in the Studio and in a script's look.
  - `npx demoman keep <video> --to <path>` saves a video's script in the repo and exports it there.
  - `npx demoman refresh` records them again with no agent and replaces only outputs whose picture changed.
  - A video attached to a pull request is kept under 10 MB.
</Update>

<Update label="0.8.0" description="Linux, and pull requests that say what was recorded">
  - Demoman runs on x86_64 Linux. Setup names the one `sudo` command that installs Chromium's libraries.
  - A video attached to a pull request carries a line saying what the run did and which commit it recorded.
  - In Claude Code, the plugin reminds your agent to attach a demo after it opens a pull request.
  - Exports on macOS draw on the GPU: one went from 93 seconds to 6.
</Update>

<Update label="0.7.3" description="A library of videos">
  - Every run belongs to a flow, and the Studio lists them with rename and delete.
  - Exported files carry their video's id, so your agent can trace a file back to its flow.
  - Videos older than 30 days lose their frames, except the ones you still need.
  - A secret in `.demoman/secrets.env` needs `DEMOMAN_SECRET_<NAME>_ORIGIN` beside it.
</Update>

<Update label="0.7.2" description="Setup asks first, and connects OpenCode">
  - `npx demoman setup` asks which agents to connect, the export quality and the pull-request setting before it changes anything.
  - Setup connects OpenCode.
  - MP4s export at High by default: 60 fps at 1440p.
</Update>

<Update label="0.7.1" description="Pull requests default to Ask, splits, and drag">
  - The pull-request setting defaults to Ask.
  - The Studio edits by splitting: cut the video into pieces and delete one.
  - A script can drag: a card across a board, a shape on a canvas.
</Update>

<Update label="0.7.0" description="Out of release candidates">
  - Demoman records in the background by default; `--headed` shows the window.
  - A saved export ends with links: Open in Studio, Reveal and Copy video.
  - The Chrome extension is retired. Demoman is the CLI and its Studio.
</Update>

<Update label="0.2.0-rc.9" description="The camera lets each step finish">
  - The camera waits for typing, a panel or a page load to finish before it moves on.
</Update>

<Update label="0.2.0-rc.8" description="Demoman keeps itself up to date">
  - Demoman updates itself in Claude Code, Codex and Cursor, and typing plays back at a human pace.
</Update>

<Update label="0.2.0-rc.7" description="Videos sized for sharing, and pull requests">
  - Exports default to a size that fits where videos get shared, and your agent can attach a video to a pull request.
</Update>

<Update label="0.2.0-rc.6" description="Codex and Cursor">
  - `npx demoman setup` connects Codex and Cursor as well as Claude Code.
</Update>

<Update label="0.2.0-rc.5" description="Your library and brand kits">
  - The Studio lists every video, and brand kits set a logo, colors and background.
</Update>

<Update label="0.2.0-rc.4" description="The Studio">
  - The Studio opens a video to trim, cut, mask and export it, in 16:9 or 9:16.
</Update>

<Update label="0.2.0-rc.3" description="Secrets belong to a site">
  - GIF and stills exports. A secret must name the one site it may be typed on.
</Update>

<Update label="0.2.0-rc.2" description="Apps behind a login">
  - `npx demoman signin <url>` saves your sign-in, and your agent can set up a demo account.
</Update>

<Update label="0.2.0-rc.1" description="First public release">
  - `npx demoman setup` installs Demoman for Claude Code, and your agent records a flow and hands you an MP4.
</Update>
